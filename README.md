## What the program implements

The program combines five independently checkable components:

1. **A partial Brainfuck interpreter core and fixed self-test**  
   The fixed program emits `S`. The interpreter implements the commands used by the embedded test. This compact interface is not presented as a complete general-purpose Brainfuck command-line environment.

2. **A canonical eight-rule output machine**  
   The default word `PLEIADES` is converted into a deterministic write-and-halt transition table. The complete table—not merely the output word—is serialized as canonical compact JSON bytes.

3. **Exact base-257 Gödel coding**  
   For serialized bytes (b), the encoder (G) and decoder (R) satisfy

   ```text
   R(G(b)) == b
   ```

4. **Byte-exact ATGC encoding**  
   Every byte is mapped reversibly to four symbols from `A T G C`. Decoding reconstructs the original serialized machine byte for byte.

5. **Exact rational and symbolic photonic model**  
   Inputs are parsed with Python `Fraction`; the program does not use `float`. Rational equalities are tested exactly, while generally transcendental quantities are retained as symbolic expressions.

## Scope and limitations

This repository provides a compact, reproducible **formal computation and encoding prototype**.

It does **not** establish:

- that `PLEIADES` was historically or physically generated by this encoding;
- a physical photonic singularity, time particle, or experimental device;
- a general halting oracle;
- termination for every program and input;
- infinite computation in finite time;
- a proof that all physical information has zero entropy;
- supernatural communication or metaphysical necessity.

The term **total-machine reference** is a project-registry designation. It does not mean a total computable function over every possible input.

The current program preserves the exact core needed for its closed-loop certificate. Earlier TM-009 variants contain additional diagnostic demonstrations such as explicit three-cycle and information-geometric fields; those historical variants remain separate.
